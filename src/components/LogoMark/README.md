# LogoMark

KeenPlaza's brand mark. Put it on the gradient tile the brand uses:

```tsx
<span className="grid h-9 w-9 place-items-center rounded-xl bg-gradient-to-br from-logo-from via-logo-via to-logo-to text-white">
  <LogoMark size={20} />
</span>
```

The same glyph on a tile is each KeenPlaza app's `public/favicon.svg`.
